# 11 — 相位切分人工标注验收（相位条上线前的门）

Status: claimed
Blocked by: 05 — MotionBERT 单目提升接入；10 — 三维相位切分与逐弯置信度

## What to build

选 10 段覆盖单人侧面、跟拍混合、犁式小弯、卡宾的素材，逐弯标注换刃与弯顶点，与自动切分对比，产出边界误差与相位帧错分率报告，给出通过/不通过。

## Acceptance criteria

- [ ] 覆盖四种素材形态，合计约 100 个弯
- [ ] 换刃时刻误差中位 ≤0.25s、p90 ≤0.5s
- [ ] 每段弯数误差 ≤1
- [ ] 相位帧错分率 ≤10%
- [ ] 未达标时给出排查结论（信号、阈值还是素材形态）
- [ ] 标注文件与对比脚本可复现

  段中位 0.200s / p90 0.284s）。
- **排查结论**（幅值/时长/置信单变量实验，证据
  `.scratch/phase-2/attack_exp/`）：检出缺口的直接原因是三信号置信门——
  BV1js4y137Mr 幅值 p90=22.1° 仍 0 弯，10 个弃弯里 9 个死于 low_confidence；
  conf→0 时 0→9 弯、clip_552_906 4→50。幅值门与时长门单变量影响小
  （≤3 弯）。置信分低的上游是 2D 交叉信号与 3D 侧倾的时机错位——深度问
  题的另一面。单纯放宽阈值不是修复（全关时 BV1wa411J7nF 检出 25 超过银
  标准 15，伪弯混入）。素材形态次因（练习动作冠状倾本就小；新手 15fps 犁
  式 2D 信号无振荡可恢复）。
- **银标准两处机制偏差已修**（对抗复核发现）：全局线性去趋势把短片段过零
  推偏 0.1~0.3s、端部卷积零填充制造幻影过零 → 改滚动均值高通（窗 ≈5s）+
