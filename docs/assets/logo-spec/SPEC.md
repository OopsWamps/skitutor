## 1. 模数体系

- 模数 m = 3u（u = 32×32 viewBox 单位）＝骨笔画宽＝板笔画宽。
- 关节换算：头 r3.6 = 1.2m · 髋 r3.3 = 1.1m · 膝 r2.5 = 5/6m · 踝 r2.25 = 3/4m。
- 层级红线：头 1.2m > 髋 1.1m，不可颠倒。
- 显示换算：1m = 3u；A 板 S = 14 px/u（1m = 42px）；C 板 = 源文件 ×1.4（1m = 11.55px）；D 板组合最小样 140px 宽时 1m ≈ 2.2px。

## 3. 组合与安全间距

- 组合定义 = 源文件整体等比重建：图形组 `translate(84 36) scale(2.75)`、字标组 `translate(190 47) scale(0.68)`、副标基线 y140、textLength 416。C 板以 ×1.4 一层缩放套在整只源文件上，图形有效 3.85×、字标有效 0.952×——字标随 mark 同步缩放，锁源比例 88 : 57.8 ≈ 3:2。
- 副标：Cascadia Mono，源字号 13，letter-spacing 2，textLength 416（两端随字标等比）。
- 副标基线口径（源 2.75×）：距图形盒底 16px ≈ 2m；距字标字面底 29.8px ≈ 3.6m。两条口径都写出，消除"= 1m"的规则-示例冲突。
- 图-字间距 = 19.0px ≈ 2.3m，口径为图形名义盒右缘（x172 源）→ 字标墨缘（x191.02 源）。
- 留白：内容名义 bbox（图形名义盒 ∪ 字标名义盒 ∪ 副标 textLength 端点）四周外扩 2m；C 板四边尺寸线全部精确 23.1px（2m），四角 1m×1m 实心小方块示意模数。
- 字面高口径：统一 85u（字稿 y8→93）；平笔画字面 84u（S 喇叭 overshoot 1u），在图内注明两套口径关系，跨套不再各说各话。
- 组合名义宽 : 图形盒高 = 730.8 : 123.2 ≈ 5.9 : 1（源 522 : 88 同比）。

## 5. 坡角与踝-板间隙量法口径

- 坡角 = atan(4.5 / 17.83) ≈ 14.2°，直段 (26.76,24.30)→(8.93,28.80)。A 板以板头为圆心 r9.5u 画弧，端点 14.24°（取整标 14.2°）。
- 踝-板间隙 0.53：板线中心线由直段两端点内插，踝心 x=16.18 处板线中心 y≈26.97，与踝心 y26.44 的竖向差 = 0.53u。口径句写在 A 板图内：这是竖向距离，非净空。
- 净空示意（A 板细部①）：板带边缘 ±1.5u 同画出（上缘 1.97u / 下缘 4.97u）；踝圆下缘 5.19u 越过板带下缘 4.97u 达 0.22u——两形刻意重叠（踩板），0.53 不是净空，图形对应与文字口径互为印证。
- 降级形（16px）= 基准路径精确 0.5 半化：板线含板尾弯头 Q（坡角 14.2° 不变；整数网格直段替代形取整 14°，即草案 13.9° 的取整口径）、红膝点 r1.25。草案舍弃清单误列"尾端上翘弧"，定稿改为保留项并列全条目。

## 6. 评审修正记录（fixes 8 条全部落实）

1. **字标未随 mark 同步缩放**：C 板弃用"mark ×4.4 / 字标 ×0.68"的拼合，改为整只源文件 ×1.4 等比重建，图形:字高 = 88:57.8 源比锁死。
2. **副标间距规则-示例冲突**：删除"与字标基线间距 = 1m"，改写两条实测口径（距图形盒底 ≈2m；距字标字面底 ≈3.6m）。
3. **图-字间距 2m 标注不实**：改标 2.3m 并注明口径边（名义盒右缘→字标墨缘），尺寸线两端落在已声明的边界上。
4. **留白锚点口径混用**：留白说明补"内容名义 bbox（图形名义盒 ∪ 字标名义盒 ∪ 副标 textLength 端点）四周外扩 2m"，四条尺寸线锚点与声明一一对应。
5. **组合最小宽 128 vs 140 冲突**：取 140px（有下限推导的一套），并给出"1m ≥ 2px 屏显 / ≥0.75mm 印刷"推导句；膝点直径统一 ≥2.5px。
6. **降级形删减条目**：保留/舍弃清单重写，Q 弯头列保留项并注明坡角 14.2° 不变与 13.9°/14.2° 取整口径，每处删减有对应条目。
7. **深底坡线对比依据**：B 板规则③补对比值 ≈2.2:1 与最小场景 ≥24px，定稿路线与理由写明（见 §2）。
8. **20× 细部圆补板缘线与净空示意**：A 板细部①画入 ±1.5u 两条板缘虚线与 0.22u 重叠标注，"非净空"口径有图形对应（放大倍率改 10×，标注如实在图）。
