# 相位切分人工标注验收报告（issue 11，相位条上线前的门）

日期：2026-10-26。状态：**工具与预标注就绪，正式判定待人工标注**。
按预标注（银标准）基线，当前结论为**不通过**；失败主体是自动切分的弯数
覆盖不足——这不随标注者改变，需要信号层改进。人工标注（约 1~2 小时）完成
后重跑对比即得正式判定。

## 方法

- **标注对象**：每弯两个时刻——换刃（edge change）与弯顶点（apex）。
- **标注工具**：`scripts/annotate_server.py`（本地页：←/→ 逐帧，E=换刃，
  A=顶点，Backspace 撤销；落盘前校验帧号与 kind、同帧去重）。OpenCV 写出的
  FMP4 编码浏览器 `<video>` 解不了，服务器启动时自动把这类视频转成 H.264
  副本（`<stem>_h264.mp4`，CRF 18 近无损，帧数与原片一致）再发送。
- **预标注（银标准）**：`scripts/preannotate_phases.py` 从独立 2D 信号生成
  候选：髋中点横向轨迹滚动均值高通（窗 ≈5s）去漂移 → 过零（复用
  `phases._zero_crossings` 的零平台语义）→ 局部膝较直弱过滤（±0.35s 窗
  nanmax ≥ 全片 p60）；首尾 0.5s 无半弯支撑的过零丢弃；相邻换刃最小间隔
  0.5s（与自动侧 MIN_DURATION_S 同规范，跨帧率一致）。顶点 = 弯内 2D 膝
  夹角最小帧。信号来源与被测自动切分（三维重力参考侧倾）独立。银标准
  **不是**人工标注，正式判定以人工为准。
- **自动切分**：生产链 `MotionBERTLifter` → `segment_phases`（幅值 ≥6°、
  时长 ≥0.5s、三信号置信 ≥0.5）。
- **对比**：`scripts/check_phase_annotation.py`。换刃**保序 DP 最大配对**
  （cap 0.75s，次优总差；顺序贪心在弯数差异大时会交叉配对/丢基数，已弃
  用）。相位帧错分率 = 双方覆盖帧上三相位标签不一致占比，参考相位由标注
  边界推导（控制段 = 顶点 ±0.25 弯长；标注文件可另存 control_start/end
  覆盖）。**口径声明**：该错分率含规则定义差——自动控制段是 50% 幅值规则，
  与四分位规则在正弦类波形上有 5%~52% 的纯定义差（完美标注在正弦波上也
  会得 ~16.8%）。因此每段同时给出**定义底线**（把自动自己的边/顶点喂进
  参考规则自比所得）与**超出底线的错分率**，验收门用超出量。

## 排查结论（信号、阈值还是素材形态）

按票面要求做了归因实验（幅值门槛 6°→3°；复核又补了置信门与时长门单变量
实验，证据在 `.scratch/phase-2/attack_exp/`）：

1. **检出缺口的直接原因是三信号置信门**。BV1js4y137Mr 幅值 p90=22.1° 仍有
   信号，default 档 10 个弃弯里 9 个死于 low_confidence（low_amplitude 仅
   1 个）；单独把 min_confidence 0.5→0：BV1js4y137Mr 0→9 弯（银标准 10）、
   clip_449_617 0→5、clip_552_906 4→50、BV1wa411J7nF 6→25。幅值门与时长
   门单变量影响都小（≤3 弯）。置信分低的上游是 2D 交叉信号（横向轨迹/
   膝周期）与 3D 侧倾的时机在单目素材上错位——仍是深度问题的另一面。
2. **单纯放宽阈值不是修复**：全门槛关闭时 BV1wa411J7nF 检出 25 弯超过银
   标准 15——置信门同时挡着真实信号与伪弯，说明信号本身区分度不足。
3. **冠状侧倾幅值被单目深度压缩**：教学素材 |lean| 中位 3.3~10.6°（竞技
   跟拍 15.7~25.1°）；侧视机位下冠状倾发生在深度轴，恰是单目最不可观测的
   方向。
4. **素材形态是次因**：练习动作（鹤弯/标枪弯）冠状倾本就小；新手犁式
   15fps 素材 2D 信号弱（clip_299_386 原始过零仅 1~3 个，任何去趋势都救
   不回，只能人工标注）。
5. **银标准自身的两处机制偏差已修**（不影响"不通过"的方向，但影响数字）：
   全局线性去趋势把短片段内部过零推偏 0.1~0.3s、端部卷积零填充制造幻影
   过零（BV19T411h7Ub 曾在帧 2 出现换刃）；MIN_TURN_FRAMES 帧数判据跨帧率
   不一致（60fps 下 0.2s < 自动侧 0.5s 规范）。修复后犁式素材检出从 8/13
   恢复到 40/66（半犁式 167s、犁式 354s 的量级才合理）；clip_299_386 仍只
   有 1 候选（信号本身无振荡）。三段犁式的银标准换刃数仍可能偏低，人工
   标注必须覆盖。

**定义与公式排查为阴性**：配对（保序 DP）、边界帧语义、conf 门槛同源性、
2D 夹角几何、标注退化输入处理均经独立复核；「向左倾为正」符号契约有测试
钉住。配对成功的弯上边界质量尚可：竞技跟拍段（FW1S3VAKui8，n=14）换刃
中位 0.200s、p90 0.284s，已接近门限；clip_552_906/BV1wa411J7nF 的中位在
0.067~0.100s。问题不在「已检出弯的时刻」，在「哪些弯能被检出」。

## 人工标注剩余步骤（正式判定用）

1. `python scripts/annotate_server.py --manifest datasets/recreational_ski/phase_annotation_manifest.json`
   → 浏览器逐段逐帧确认/修正预标注（预计每段 5~15 分钟，共 1~2 小时）。
   重点：clip_299_386（银标准只有 1 候选，需手标）；三段犁式银标准偏低，
   以人工数为准；每段补齐银标准遗漏的弯。
2. 重跑 `python scripts/check_phase_annotation.py --manifest ...` 得正式四门
   判定，更新本报告。
3. 预期管理：弯数覆盖缺口在自动侧，人工标注不改变它——正式判定大概率仍
   不通过。数字将用于：相位条上线决策；信号改进方向（置信门对单目素材的
   适配、或多机位深度量化后重估）。
